# 한눈에 보는 근현대사 타임라인 (1800 – 현재)

시대별로 **해외(서방 · 아시아) — 연도 — 국내(한국)** 3열로 나누어 굵직한 역사적 사건을 배치한
단일 HTML 페이지입니다. 근현대(20세기 이후)로 올수록 **경제** 사건의 비중을 높여 세계 경제사의
흐름과 한국 경제의 궤적이 나란히 읽히도록 구성했습니다.

## 보는 방법

- **웹(GitHub Pages)**: https://ssyj874-collab.github.io/target-price-tracker/timeline/
  — `gh-pages` 브랜치의 `timeline/` 폴더에서 서비스됩니다. 내용을 갱신하면 같은 주소에서 새로고침으로 확인할 수 있습니다.
- **로컬**: `index.html`을 브라우저에서 열면 바로 동작합니다 (외부 의존성 없음).

> 참고: `gh-pages` 루트의 `index.html`은 별도의 KOSPI/KOSDAQ 리포트 페이지이므로 건드리지 않습니다.
> 타임라인 배포는 `gh-pages` 브랜치의 `timeline/index.html`만 교체하면 됩니다.

## 구성

- **9개 시대 구분**: 근대의 여명(1800–1863)부터 팬데믹·인플레이션·AI(2020–현재)까지
- **143개 사건** (경제 76개): 정치·외교 / 경제 / 전쟁·분쟁 / 사회·문화 4개 유형
- **역대 대통령 14명의 임기 배너**: 취임 시점에 임기·주요 비고(하야/서거/파면 등)를 표시, 상단 토글로 켜고 끌 수 있음
- 상단 필터로 유형별(예: 경제만) 보기, 시대별 바로가기 내비게이션
- 데스크톱은 4단 그리드(서방 | 아시아 | 연도 축 | 국내), 모바일은 연도 축 기준 1단 배치
- 라이트/다크 모드 자동 대응

## 데이터 수정

사건 데이터는 `index.html` 안의 `EVENTS` 배열에 있습니다. 항목 형식:

```js
{ y: 1997, r: "kr", t: "eco", title: "IMF 외환위기", d: "설명…", span: "1997–98"(선택) }
// r: west(서방) | asia(아시아) | kr(국내)
// t: pol(정치·외교) | eco(경제) | war(전쟁·분쟁) | soc(사회·문화)
```

시대 구분은 같은 파일의 `ERAS` 배열에서 수정할 수 있습니다.
